# MR Memory 开发记录

本文件记录公开实现变化。个人聊天、真实查询、人物称呼、群账号、人工标准答案和运行快照不得写入公开仓库。涉及真实数据的调查与验收材料仅保存于被 Git 忽略的私有开发目录。

## 2026-09：恢复性开发

- 连续请求保留有界来源指针并按当前快照重新读取；生成的回答不是后续请求的事实来源。
- 持久记忆核验完整来源关系，显示配额只限制呈现；Reader 后复核选中依赖，区分无关写入和真实来源变化。
- 整理的图提交、覆盖与来源进度保持事务一致，索引失败单独记录，取消等待数据库事务完成。
- Resident Reader 的人物、作品、实体和主题指称贯穿证书与回答上下文；陈述对象与证据说话者分别保存。
- 主模型接收紧凑语义简报；原始摘录、持久身份键、来源键和内部审计对象保留在插件内部。
- 简报保留归因、指称有效时间、冲突、未决问题和限制条件；实际呈现的事实及来源通过独立宿主元数据记账。
- 宿主从 REQUIRED atoms 推导必需事实列表，并根据已选择账号确定合法身份绑定模式。证据校验不改变模型选定的账号。
- 回答中的字面匹配仅作为诊断信号，不构成语义通过结论，也不奖励复制原始摘录。
- 测试使用合成消息和身份；协议测试与真实请求的效果、时延、成本验收分别记录。

历史研究材料不作为当前版本的效果证明。当前线上结论应来自同一真实请求经过检索、Reader、注入与最终回答的完整链路，并同时列出失败与缺失证据。
