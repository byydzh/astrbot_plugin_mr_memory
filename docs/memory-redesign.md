# MR 重构：让共同经历改变理解方式

MR 的目标是让 bot 在持续交往中形成属于这段共同经历的理解：知道彼此正在经历什么、怎样理解一句话、哪些事尚未结束，自己的参与又改变了什么。旧经历应影响它在新情境中注意什么、怎样联想和理解；后来发生的事也应改变旧认识。为 AstrBot 提供本轮语义背景，是这个持续过程的一次用途。

截至 2026-09-20，`codex/mr-memory-redesign` 实现了可修订的经验网络、共享注意和理解过程回流，但五轮“完整三十分钟产品反思、实现、审查”后仍未达到可替换线上的效果。原生调用证明路径能够运行，也暴露了人物归属、反讽、概括范围和最终表达的问题。开发分支保持实验状态；具体私有样本、输出和费用保存在仓库外现有的私有工作记录中。

**目前的架构和各自责任**

原始交流、当前理解和长期网络承担不同作用：

- 原始交流保存作者、时间、引用、实际 bot 回复与工具事件，是可以重新阅读的经历。记录了一次发言，不等于发言内容已被证实。
- 长期网络保存可修订的经历、概念、关系、解释、开放问题与模型自行组织的表示。具体人、事件和更高层认识都可成为连接端点；连接本身也可被引用和重新解释。
- 当前理解保存模型选定继续关注的图地址及关注原因。每次输入读取对象当前版本，后台改变的正文、表示、把握和连接也随之进入后续工作。
- 理解过程保存当时实际提供给模型的材料、模型自己的解释、交付背景，以及主意识后来实际留下的参与。它能成为之后重温的材料，但模型的自述不是内部因果的直接观测。
- AstrBot 继续承担公开表达、网络搜索、图片等外部行动。MR 可以按需读取主意识已有输入和工具目录；MR 的文字视图不代表主意识看不到图片或不能执行工具。

~~~mermaid
flowchart LR
    E[新交流、引用与实际 bot 参与] --> W[延续中的理解]
    G[可修订的经历、概念和关系网络] -->|读取当前认识| W
    W -->|修改内容、表示、连接和关注| G
    W -->|相关含义与可选原始交流| A[AstrBot 主意识与原有工具]
    A -->|实际回应和行动| E
    W --> X[保存本次理解过程]
    E --> X
    X -->|后续使用、比较和反思| W
    G --> R[模型留下的继续思路]
    R -->|既有工作时段和额度内继续| W
~~~

前台和后台共享记忆与修改能力，因等待时间和资源要求不同而采用不同工作方式。前台可以立即保存新理解；后台可以理解新交流、反思实际反馈、继续此前留下的思路。消息覆盖进度只说明哪些材料已处理，不表示某件事已经理解完毕。反馈学习仍有原有独立额度；回答前检索不计入这两个后台额度。工作时段沿用服务当地时间。

实际模块边界：

| 模块 | 责任 |
| --- | --- |
| `memory_graph.py`、`store.py` | 原始观察、可寻址记忆、连接、修订与访问 |
| `cognition.py` | 共享关注、理解过程、下一轮延续与重温入口 |
| `agent.py`、`memory_protocol.py` | 原生模型调用、主动读取、模型决定的修改与完成交付 |
| `learning_writes.py` | 独立保存、失败草稿、进度恢复；不替模型补造语义 |
| `handoff.py` | 将模型选择的解释和来源传给主意识，保留作者、时间和当前把握 |
| `main.py` | AstrBot 生命周期、消息记录、资源调度和请求接入 |

**主动搜索和高层联系需要保留的能力**

[MRAgent](https://arxiv.org/html/2606.06036v1) 的主动重构继续作为检索基础：下一步读取可以依赖刚看到的内容，Cue–Tag–Content 提供多粒度导航；模型也可搜索原文、打开前后文、沿任意记忆及连接继续。不能以固定召回或预先写好的语义规则代替这条路径，再把能力减少称为提速。

高层认识需要保留可重新绑定的关系结构：一段经历里的具体参与者和活动可以变化，角色之间的关系、不同解释及适用条件仍可能用于新情境。图允许模型创建这种表示、联系实例、拆分旧概念或重新组织联系；没有预设只能逐级形成更空泛的摘要。TEM 研究了其训练任务中的结构泛化，可作为设计启发，但外部 LLM 写图不是该模型的复现。[Whittington 等，2020](https://pmc.ncbi.nlm.nih.gov/articles/PMC7707106/)

| 想获得的行为 | 架构必须提供的实际作用 |
| --- | --- |
| 由零碎线索认出情境 | 当前理解参与新输入解释，同时可以主动回看具体经历 |
| 类比与迁移 | 关系结构与具体角色可以分开表示，在新事中重新绑定和比较差异 |
| 重温常用认识 | 带回它参与过哪些理解、实际发生了什么，而不只累计打开次数 |
| 纠正错误联系 | 改写仍在使用的原认识、表示及有关连接，保留改变来历 |
| 主动探索 | 模型留下自己的问题和进展，后续资源给予继续机会 |
| 学习理解方式 | 自己的真实参与和后果能够改变以后的注意、访问与解释 |

这些能力共享同一模型、网络和工作状态，没有分别建立固定的思考流水线。接口提供表示容量；只有后续行为实际受益，才能说高层联系发挥了作用。

**不确定性贯穿使用和修订**

每项认识和连接携带模型自定的 `belief`。正文、表示、检索、图导航、工作集、历史版本和交付都保留它。未评估的解释为未确认；原始消息只确认记录了那次发言。熟悉程度、联想用途和事实把握分别理解，不通过访问次数换算置信度。

未经认可的模型解释保持暂定。多次独立经历、针对该解释的明确肯定可以强化认识；自述、称呼偏好或纠正本身有相应效力，无需等待夸赞。反馈在回应哪种含义、是否反讽、赞同的是事实还是表达，都由模型理解。沉默不是认可，复述同一次经历不增加独立支持；负面反应可以促使重新理解、削弱或撤回联系。

依据发生变化时，当前读取能看到直接的 `basis_changed` 和相关认识入口。模型可以继续沿图判断影响，程序不把局部变化自动扩散为整张图的撤回。当前没有每次读取都遍历全部间接依赖的新机制，也没有经过训练的概率校准器。

重温的价值来自将旧事与新经历共同理解，可能形成新联系、缩小解释范围，或建立更短的访问路径。反复把相同摘要交给冻结模型，不自动形成独立经验。重放研究中的未来使用需要和可能更新收益可以启发模型取舍，但本项目没有已知的社交奖励函数，不能直接搬用数值公式作为成熟调度器。[Mattar 与 Daw，2018](https://pmc.ncbi.nlm.nih.gov/articles/PMC6203620/)；[Kumaran 与 McClelland，2012](https://stanford.edu/~jlmcc/papers/KumaranMcC12REMERGE.pdf)

**这次实现保留了什么，淘汰了什么**

调用内相同版本的正文、反思和连接重复内容现在用已有地址引用；更新版本与不同内容仍完整传递。模型自建表示、把握和关注不会被消息压缩器误当作平台字段。主动搜索、原文、主意识输入访问和用户模型配置保留。

前台增加上一轮理解与之后实际交流的延续入口；更完整的历史仍可按需打开。不能把历史上旧系统回复收到的反馈归因于现在重新生成的实验回复。全量覆盖共享注意的试验已删除，采用原有逐项关注修改，避免抹掉并行工作的选择。

旧前台失败草稿由后台承接，前台只处理本次形成的变化。后台恢复时拥有明确的草稿集合，保存或修正它们时保留后来并行产生的草稿；没有新消息但有这些草稿时，也有正常后台调度入口。失败仍显式保留，不靠假报消息已整理来解除等待。

交付支持自然文本或带把握、可选来源的解释。模型可选择同时提供原始发言和当前记忆；相同来源只展开一次，记忆仍标明为模型理解。等价的字符串包裹 JSON 和消息地址形式得到处理。可选地址失败会明确显示，不抹掉其他有效内容。这是信息传递能力，不是语义审核。

最后可用模型轮采用原生 `tool_choice=none` 与 JSON 交付，避免耗尽轮数后只留下未完成工具请求。原生诊断确认：即使工具表相同，改变工具选择或输出模式仍可能改变服务端有效前缀、损失缓存。当前保留完成交付，也保留这项明确的成本缺陷；没有宣称同时解决可靠完成与完整缓存复用。

以显式打开记忆次数代表认知重温的旧运行读取已删除。旧数据的删除清理仍保留，避免用户删除来源时留下历史对象。

**目前的证据改变了哪些判断**

五轮有限原生观察均未达到产品目标。观察保留配置中的 DS/Poe provider、人格、主会话、媒体、真实工具声明和历史时间范围内原文；主动记忆工具在私有副本实际执行。外部主工具未执行，因此请求了外部工具的主回答记为未完成。这不是历史 HTTP 请求的逐字节复现，也不是广泛统计结论。

开发起点的对照并非历史上“效果完成但太慢”的最佳旧版本，不能据此声称已超越那个版本。新一轮按时间预选的未见输入也没有解决过度概括和反馈理解；因预算不足未发出的主调用仍是缺失证据。

已有正向观察是：模型能够找到同一账号的旧交流，形成自建表示，修改部分已有认识，并在虚构连续互动诊断中理解一次反讽和方法认可。虚构诊断仅证明局部可能性；它没有真实主模型参与，也不等于群聊效果验收。

现实限制更关键：

- 原始作者和新背景正确时，主模型仍可能沿用旧称呼或把人和 bot 的经历混淆。MR 图与主会话各自累积理解，当前没有让二者稳定协调的机制。
- 将 `belief` 写成暂定，不妨碍同一对象正文使用确信语气；原生观察确实发生了这种矛盾。字段不是学习成果。
- 对反馈的理解会出错，读到了上下文仍可能把反讽当确认，或把几个不同自述扩大成稳定特征。
- 模型选取原文交付有助于保留区别，也会带来大段旧回答和重复解释。更长的上下文没有自动转化为更好的判断或更简短的群聊表达。
- 当前主模型请求中仍有用户设置的简短回复要求。问题不能归结为漏传该设置；一次去掉旧历史的诊断也不足以证明清空历史是修复。
- 没有证明高层联系在未见交流中带来稳定迁移、降低重复推理，或使反馈可靠地改写依赖它的认识。

**理论边界和下一步主线**

现有 API 不开放基础模型权重更新；可塑的是外部状态、访问路径和后续推理条件。外部网络能够改变行为，但不能把可存储任意 JSON、增加连接或反复调用当成已经训练出了认知能力。[Generative Agents](https://arxiv.org/html/2304.03442v2)、[A-Mem](https://arxiv.org/html/2502.12110) 和 [Reflexion](https://arxiv.org/html/2303.11366v4) 提供部分研究依据，不保证本项目在当前模型与资源下达到同样效果。

压缩必须选择信息。固定短摘要无法保留任意未来任务需要的全部区别，因此原始经历和主动再读取仍重要。当前背景应补充此刻缺少的信息；长期表示则要支持以后重新展开。图更密、路径更短不是收益本身：需要相关经历可达，又能保住人物、时间和关系方向。语义取舍继续由模型完成。

费用收益应来自跨次复用：形成的认识在以后减少重复工作，并在新经历下得到有用修订。它必须抵偿形成和维护的代价；缓存节省只是其中一部分。串行发现仍有延迟，有限模型也可能在完整信息下理解错误，不存在靠图结构直接消除这两种上限的保证。

下一阶段优先研究一条完整因果链，而不是继续增加图类型或把握字段：

1. **协调当前理解与主意识历史。** 明确当下参与者、正在回应的事情和正在修订的认识怎样共同进入生成；旧 bot 说法作为发生过的行为仍可回看。不能默认一份正确 MR 摘要就能覆盖另一条持续上下文中的旧判断，也不能把全部历史改成观察文本视为已验证的答案。
2. **让实际参与的后果改变仍在使用的解释。** 对应本系统实际生成的回答与其后续交流，重温相关理解及其依赖，观察这些变化是否参与之后的新场景。历史反事实回复不能借用旧回复收到的评价；模拟互动要明确区分能力诊断和产品证据。
3. **围绕这种复用再做费用和时延取舍。** 比较理解质量、最终参与、反复读取代价与缓存损失；对高层联系做有针对性的消融，判断它们是否有实际贡献。尚未证明贡献的框架不应凭存储与测试通过进入线上。

这三项是下一步研究建议，尚未宣称完成，也没有自动启动第六轮。开发分支保留为实验；线上只独立修复已复现的运行故障。部署继续使用插件热重载，保留既有模型、配置、前端与服务生命周期，私有材料不进入仓库。
