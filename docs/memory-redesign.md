# MR 重构：让共同经历改变理解方式

2026-09-19 设计重审，2026-09-20 延续实现。本文取代上一轮以“统一可修订记忆图”为主要目标的开发计划。开发分支 `codex/mr-memory-redesign` 已接入共享的当前理解、模型自建表示、使用经验回流与可修订的把握程度，尚未部署。下面区分产品目标、设计假设与当前实际能力；真实模型观察不能由存储或接口测试替代。

**开发分支要实现的产品目标**

MR 应让 bot 在持续交往中形成属于这段共同经历的理解方式：知道大家正在共同经历什么，如何理解彼此的话，哪些事情还没有结束，自己先前的参与改变了什么；能够由旧事想到新事，也能因新事重新认识旧事。这些理解应影响它下一次首先注意什么、怎样联想、如何解释一段从未见过的交流。

为 AstrBot 提供语义背景，是这套持续理解在一次回应中的用途。项目的研究目标还包括：经历能否让系统形成自己的中间概念、发展可迁移的关系结构，并改善以后理解和回忆的方式。网络搜索、图片生成和公开表达继续由 AstrBot 及其原有工具承担。MR 内部的自发思考不等于新增自动发言功能。

因此，长期学习的对象至少包括内容、表示和注意方式。记住更多事情、给旧摘要增加关联、把一次纠正保存成功，都不足以单独说明达到了这个目标。判断应落在后续未见交流里：同一个基础模型是否因为这些共同经历而形成了不同且有用的理解，能否继续成长，而不是每次依赖开发者指出它该学什么。

**上一轮哪里把目标降格了**

统一地址、可引用的连接、共享写入和版本，是必要的实现能力。但是：

- “允许存放高层认识”只给出了表示容量，没有构造出高层认识参与日常理解的方式。把一段总结标为 pattern，不能证明它会解释新情境。
- 当前调用仍围绕“回答这道问题”和“处理完这一批消息”组织。图主要在模型主动查询时作为外部资料出现；对新经历的理解、记忆的组织和之后的注意没有成为同一持续过程。
- 工作状态仍以单段延续文本为主。它能说自己记住了什么，却没有把当前关系、情境、未完事项和相关长期认识组织成持续使用的工作状态。
- reconsider 记录的是显式打开 memory 工具的活动，不等于某条记忆实际参与了怎样的理解。检索结果也可能直接提供内容，主意识是否采用它更不能由一次工具打开推断。
- 提供活动目录和自由读写工具，不等于模型已经学会选择重温、比较经验、产生新概念。把语义交给 LLM，仍然需要设计这些决定如何留下状态、进入下一次实际输入并获得后续经验。

这些是对 0cbb153 路径的结构判断。它们没有把上一轮有限的模型观察扩大成对任意一次线上错误的因果解释。

**运行的中心是持续的理解状态**

系统维护两种相互作用的状态：长期可塑的经验网络，以及当前正在使用它的理解状态。原始观察保留为可重新体验的底本。

长期网络容纳具体经历、关系、概念、情境模式、仍在考虑的可能性，以及对自身参与和理解方式的认识。当前理解状态包含被激活的网络片段、参与者在当前事情里的角色、正在采用的解释、尚未闭合的事项和下一步关注。它可以同时保留几条相关思路；每次调用得到的是适合本次工作的视图。实现上不必为这些语义各建一个服务或固定类型表。

这个状态必须真正参与输入组织：已经在当前事情中使用的人、关系和概念，按其当前版本进入下一次理解，而不是先被压成一份自由摘要，再等检索碰巧找到。后台改变的认识也应改变这个视图。过去的看法仍是经历的一部分，当前使用的含义则保持可更新。

~~~mermaid
flowchart LR
    E[新交流与 bot 实际参与] --> W[延续中的理解状态]
    G[可塑的经验与概念网络] -->|唤起经历和理解方式| W
    W -->|重组内容、概念和注意方向| G
    W -->|本轮相关的语义背景| A[AstrBot 与原有工具]
    A -->|实际回应、动作及后续交流| E
    W -->|留下值得继续的思路| R[有资源时重温、比较与探索]
    G --> R
    R -->|重新认识旧事、形成新联系| G
    R -->|改变以后如何理解| W
~~~

一次工作可以从新的交流、延续中的事情、旧经历的重新唤起或模型自己留下的问题开始。模型结合当前状态决定需要读什么，读到的内容又改变当前解释和下一步访问方向；形成有用认识时同时修改长期网络、当前状态及继续关注的内容。需要回应时，把当下有用的含义交给主意识。未完成的思路可以在后续工作中继续。

前台和后台是这个过程受到不同时间、资源要求时的工作方式。及时理解不必等待深度整理完成；后台的意义也不限于把原文批次转换成摘要。保留真实的未读进度，以便覆盖新材料，但不把“标记完成一批”设为认知活动的最高目标。

这个外壳仍然可以写成通用的读写循环，因此仅画出循环并不构成改进。真正需要落地的是：长期认识参与新经历的解释；当前解释决定回忆与重组；使用后的经验再次参与学习。三条因果路径都必须实际运行。

**高层网络需要学到怎样的表示**

具体经历需要保留事情的结构：谁在怎样的情境中对谁做了什么，当时如何被理解，之后发生了什么。同一个人可以在不同事件中承担不同角色，同一段经历也可以同时属于多个主题。平台作者和引用信息仍作为观察提供，自然称呼、话语指向和关系含义由模型理解。

高层认识则应能被带入新情境。模型可能从几段不同经历中发现一种共同的互动结构，并提出一个有用的中间概念。它应保留具体角色如何对应、哪些差异会改变解释、能回到哪些实例。以后换了人、换了话题或表达方式，模型仍有机会把这个结构用于理解；新经历也可能促使它拆分这个概念、改变适用范围或舍弃原来的组织方法。

这种抽象既能向下帮助解释具体经历，也能横向连接表面并不相似的事情；多个抽象还可以共同形成新的理解。层次是网络中的关系，不预设只能“原文、摘要、主题”三级，更不要求所有内容都向一个越来越空泛的总总结合并。

关系结构与具体内容可以分离又重新绑定，为跨情境迁移提供了一个可研究的机制。TEM 在其训练任务中研究了这种结构泛化；这里借用的是设计思路，没有把 LLM 写图视为 TEM 的复现。[Whittington 等，2020](https://pmc.ncbi.nlm.nih.gov/articles/PMC7707106/)

高层表示还必须能改变访问方式。新形成的概念要成为可检索、可联想的入口，连接到能够说明它的经历；在相关情境中被采用后，可以留在当前理解状态中，使下一次不必重新拼出全部来历。只有长文本内容变化、而注意与访问方式完全不变，仍然很容易得到一座不断长大的笔记仓库。

一个完全虚构的思想实验可以说明这里要求的变化。模型在几次不同的共同活动中，逐渐认识到某种表面的相互挖苦，实际上参与了彼此确认投入、继续合作的过程。以后出现全新的活动，模型能从角色与互动进展想到这些经历，并尝试理解新的话语；某次认真争执又使它区分出两种不同情境。值得保留的学习可能是新的关系模式、几段旧事的重新解释，以及以后会注意的区别。只给某人新增“爱挖苦人”的属性，就丢失了这类学习。这个例子说明表示需要具有的作用，不作为预设社会规律、提示词范例或专门验收题。

联想关系允许探索；依据关系帮助理解一项认识怎样形成；角色和语境让相似结构能够组合而不混淆人物。它们都由模型表达含义。图结构提供定位、双向访问和局部改写，不通过昵称、关键词或固定跳数替模型裁决语义。

**重温要成为学习的一部分**

回忆一次经历，可以使它与当前经历共同进入理解。由此产生的价值可能是新联系、新概念、对旧事的重新解释，也可能是发现先前概括过宽，或认识到一条常用路径可以更直接。一次回忆没有产生这些变化，也可以结束；没有必要为每次访问编造一项新认识。

因此需要保留的使用经验比访问次数丰富：当时为了理解什么而想起它，采用了怎样的解释，给主意识交付了什么，实际交流后来怎样发展，哪些问题仍值得继续。系统记录可观察的输入、输出与引用；模型对哪些记忆发挥作用的归因是一种可修订的解释，不能冒充对模型内部因果的直接观测。

经常参与理解的记忆，会持续带回新的使用情境。它们值得更多重新理解的机会，也值得形成较短的访问路径。与此同时，一个不常出现但能重新解释许多事情的经历，也可能值得更多注意。安排反思应考虑以后可能用到它的程度，以及继续思考可能带来的变化；频次只是其中的材料。

Mattar 与 Daw 的重放模型以未来决策的使用需要和更新收益解释访问选择。MR 可借用这个取舍来让模型安排工作，但没有已知的社会互动奖励函数，也不能直接套用该论文的数值公式当作成熟调度器。[Mattar 与 Daw，2018](https://pmc.ncbi.nlm.nih.gov/articles/PMC6203620/)

重温也不等于把同一段摘要重复提交给同一个冻结模型。真正可积累的变化来自重新激活不同经历、引入后来获得的理解、比较不同解释，以及实际交流带来的反馈。由相互作用的经历产生新关系，是 REMERGE 研究的一个机制；它支持探索递归重构，不证明重复调用本身会让 API 模型变聪明。[Kumaran 与 McClelland，2012](https://stanford.edu/~jlmcc/papers/KumaranMcC12REMERGE.pdf)

旧认识被多次引用，不应被当作出现了多份独立经验。为思考构造的可能情境也仍是想象。把它们放回共同思考并不需要层层审批，但需要让模型能看见自己究竟在重温观察、沿用解释，还是考虑一种可能性。

**丰富的思考模式怎样获得实际支撑**

这些活动共享同一个模型、网络和理解状态，不各建一套强制流水线：

| 思考活动 | 网络和运行过程要提供的能力 |
| --- | --- |
| 由零碎线索认出当前情境 | 当前理解参与解释输入，线索可唤起有来历的经历和概念；仍能沿新线索主动搜索 |
| 类比与迁移 | 具体人物和内容可与关系结构分别表示，在新情境重新绑定，并比较关键差异 |
| 形成或改变解释 | 几段经历和几种可能理解可以共同进入工作状态，后续信息能改变解释及有关连接 |
| 对未完事情产生预期 | 保留事情的进展、关系和未决问题，使后续反应有机会被理解为延续或变化 |
| 重温与重新组织 | 已有理解能回到原经历，与后来经历共同理解；允许拆分、合并概念及改变组织角度 |
| 学习自己的理解方式 | 把 bot 的真实参与、曾采用的理解与后续交流放回经验中，形成可迁移、可修订的自我认识 |

“自发”需要具体的实现含义：模型可以在一次正常工作中留下自己想继续探索的问题、关联对象、已有进展和适当的继续时机；资源调度让它获得后续机会。它还需要浏览更广网络的入口，能够改变先前选定的问题，而不被一个永远只看近期错误的队列困住。语义选择由模型完成，程序负责持续性和既有资源配置。

仅提供自由工具而没有稳定进入后续输入的状态，容易把自主性变成偶然行为；要求每次固定完成归纳、反思、核查，又会把思考变成昂贵仪式。拟建架构把延续思路与真实经验作为持续输入，让模型决定本轮怎样工作。

**研究依据与我们正在提出的假设**

MRAgent 的核心价值仍须保留：下一步记忆访问可以取决于刚读到的信息，Cue–Tag–Content 提供多粒度的方向选择。拟建网络应承接这条主动重构路径，并把重构得到的有用联系转化为以后可使用的结构。不能用静态召回或预先整理取代它，再把速度改善算作同等能力的提升。[MRAgent 原文](https://arxiv.org/html/2606.06036v1)

Generative Agents 让反思重新成为后续反思的材料；A-Mem 研究新经历进入时如何改变旧记忆的表示和联系。这些机制给出部分研究依据，但不直接证明当前群聊、模型和预算下能形成上面的连续认知过程。[Generative Agents](https://arxiv.org/html/2304.03442v2)；[A-Mem](https://arxiv.org/html/2502.12110)

本文提出的工程假设是：如果已有理解参与新经历的解释，记忆使用及其后果参与后续学习，而且新学到的概念会实际改变访问与注意，那么冻结模型也能通过可塑的外部状态改善后续理解。单纯增加记忆量或提高检索命中，并没有提供同样的机制。

这是功能性、可检验的假设。现有 DS API 不向本插件开放参数更新；我们改变的是外部表示和推理条件。图表、向量索引和回忆计数本身都不是一个经过训练的连接主义模型，也不能以脑区术语掩盖这一差别。基础模型的理解能力仍然影响上限；项目需要研究外部网络能怎样放大和延续它已有的能力。

**时间、费用与理论取舍**

网络的计算价值应来自反复使用后形成的可复用结构。一项原先需要多次回查才能理解的关系，后来可以直接进入当前理解；遇到新差异时，再展开对应经历重新理解。高层认识由此同时承担泛化和减少重复推理的作用。

这需要付出形成与维护结构的代价。只有后续复用节约的工作和带来的理解收益超过这些代价，才值得继续投入。模型规划可以参考实际使用、此前代价和未解决的问题；前缀缓存与批量独立读取仍然有用，但不能替代这种跨次计算的复用。

原始资料到长期表示、再到本轮语义背景，是两次不同的选择。前者要为未知的后续情境保留可重新展开的区别；后者要补充主意识此刻缺少的含义。固定短摘要无法保证保住任意未来任务需要的区别，因此保留可主动回看的原始经历。背景长度由本轮所需信息决定，不由“潜意识必须输出多少字”决定。

复杂网络的启发在于局部组织与跨情境联系同时存在。需要能跨越表面不同的经历，也需要沿具体关系保持方向；图变得更密或平均路径更短，本身不是认知改善。盲目全图扩散会把大量无关内容带进来，层层语义过滤又可能切断有用路径。这里的设计选择是可由模型选择和改变的条件化联系、多粒度入口和主动访问，而不是先拍出一组扩散系数。

串行发现仍有真实的时间成本，未知的未来也无法全部提前计算。费用有限时，系统需要选择此刻理解到什么程度、哪些思路值得以后继续。这是持续学习本身的资源分配问题，不要求每次回应前执行一轮完整深度反思。原有服务当地工作时间、模型配置和不同费用额度继续有效。

**本轮替换的过程与仍需证明的能力**

保留可靠的原始观察、已接通的主动访问能力、统一可修订存储、原生模型调用、用户配置与前端。已有代码是否保留，取决于它能否承担新过程中的实际责任。

本轮重做了调用组织和理解状态的实际传递路径：前台和后台每轮都读取模型选定的认识的最新内容；新的理解过程连同主意识后来实际留下的回应成为后续可读取的经历。消息整理、反馈与重温使用同一张图，已有费用分类仍保留。模型形成的表示和关注现在有实际进入下次输入的路径，是否由此产生有用的跨情境理解仍需观察。

独立工作摘要已迁入图，以显式 memory 打开次数代表回忆经验的运行路径已删除。原始消息的覆盖进度继续独立保存；完成一批可以留下尚未结束的思路。它与某件事是否已被穷尽理解是两件事，不会靠隐藏未读材料消除积压。

第一段实现必须同时展现在线理解、记忆使用后的再学习、以及高层认识对后续新情境的实际作用。不能再把“表已经统一，模型可以写任意类型”设为足够的阶段目标，然后把其余部分无限后移。

观察以连续经历及之后尚未见过的交流为单位。在相同主模型、人格、上下文与工具条件下，检查认识是否改变后续理解、是否有跨情境迁移、是否减少重复计算。将高层联系暂时拿走后，如果理解和计算过程没有变化，就不能把这些联系当作已经发挥作用。开发不围绕用户点名的句子写专门路径，也不把含未来记忆的历史回放当作真实质量对照。本次尚未进行这类验证。

**实现与验证的准确位置**

0cbb153 已实现统一可寻址对象、可引用关系、Cue/Aspect 双向导航、共享读写和修订、活动与变化目录，以及主请求公开输入的按需读取；旧独立记忆运行时已换成一次迁移后的共享存储。前端和原设置保留。

此前原生模型调用证明新路径可以读取并保存内容，也暴露了过度概括等问题；没有证明稳定的自主重温、结构迁移或最终群回复改善。历史请求使用的开发副本含后来记忆，不能作为历史环境质量评测。该提交作为可用实现材料保留，产品目标和后续设计以本次重审为准。

本轮在同一开发分支实际替换了以下路径：

- `cognition.py` 维护模型自选的工作集及实际理解过程。工作集只保存图地址和模型写下的关注内容，使用时读取当前正文、表示与连接。没有独立的事实副本、按语义编写的 gate 或程序设定的注意优先分。
- `representation` 的字段和嵌套由模型决定；`attention` 与 `recollection` 接受模型自定内容。它们不被消息压缩器误当成平台字段。新对象可在同次保存中互相连接，原始消息也可作为只读观察被图引用。
- 前台 `complete` 通过一次原生工具调用交付背景并保存本轮形成的认识；后台的修改会进入后续前台和仍在继续的后台上下文。未变化的调用前缀保留，新工作集的实际体积参与原有额度估算。
- `reconsider` 提供真实送入模型的记忆版本、它自述的理解、本轮背景与后来的实际回应。可见性和模型自述不冒充因果证明。新的前台经历可引起后续学习，后台保存一条过程记录不会无限触发自己。
- 前端可以阅读当前理解、自建表示、继续关注的内容、连接及有关理解过程；用户原有配置与各类额度继续生效。

外部状态能够改变，不自动等于已经学会怎样改变。连续观察使用空的开发记忆库、按时间提供的原始交流、两次后台学习和六次原请求；使用真实 AstrBot provider/parser 与记忆工具，历史主回复仍是旧系统的观察，不能归因于新背景。它不是同环境主回复质量对照，也没有导入后来生成的记忆冒充当时知识。

模型确实创建了连接的连接、自建表示，并在后续交流中修订认识和关注。但它也把错误的人物指向继续写进新认识，把 MR 看不到的内容推广成主模型看不到，过度解释简单的称呼调整；当前注意持续增长，多数回忆仍用了接近整段调用额度。这些问题说明，现阶段有了可变化的表示和持续路径，尚未形成足够好的修订、取舍与跨情境使用行为，不能把它当作已完成的连接主义产品。

运行观察还暴露并修复了两个通用接口问题：只用于统计的输入扫描误把失败草稿当成已保存记忆，空地址导致后续调用中断；正常完成最后一轮却被标成未完成。前台现在每轮看见实际资源，工具表和工具选择方式保持稳定。错误的格式要求、统计失败和预算提示不应替模型决定语义。未交付背景、尚未保存的变化与正常完成仍分别记录。

下一阶段要检验并改进的是经验对后续解释的实际约束力：形成新判断时能否重新组织旧判断，而不是只往图里追加另一段话；后来的交流能否改变那些经常被采用却不合适的认识；新概念能否帮助理解未见情境并减少反复回查。继续堆对象类型、连接数量或强制核查步骤不能回答这些问题。开发分支保持实验状态，不据此替换线上版本。私有连续观察的具体内容、配置差异与费用保存在项目现有私有状态记录中，不把群聊语料写入仓库。

**不确定性服务于持续交往，而不是封锁联想**

本次先完成了完整三十分钟的产品反思。需要保留的能力是：敢于形成暂时理解，带着它参与，因后来的经历改变看法。联想是否有用、对事实有多大把握、因反复接触而变得熟悉，是不同的事情。不能把一次玩笑固化成人格，也不能让每条弱联系都先通过审核才能参与思考。

实现上，每项认识与连接都有模型自定的 `belief`，可表达目前看法、支持、反例、其他解释和变化来历。未评估的解释默认为未确认；原始消息只确认记录了那次发言。反复读取不会增加确认次数。明确的自述、偏好或纠正有其适用范围；对模型解释的沉默不构成认可，赞美表达也不自动确认其中的个人事实。由 LLM 理解反馈对象、反讽和证据是否独立，程序不设置情绪规则、分数阈值或调用次数转置信度的公式。

把握程度随正文一起进入修订历史、工作集、搜索和图导航。重温同时提供当时版本与现在版本，以及实际回复之后的邻接交流；邻接关系本身不被标成肯定或否定。多个过程涉及的当前记忆仅提供一份。撤回的形成依据仍可见其来历和原因，变化目录返回直接依赖它的认识入口；是否需要进一步改写、怎样影响更高层认识，仍由模型判断，不自动连带撤回整个子图。尚未解决的问题可以继续关注，也可以暂时移出注意。

交付背景可以是一组带各自把握程度的解释，也可以是自然表达程度的简短文本。不会为了置信度另加一次模型核查。前端可读当前把握及依据变化。同批写入按显式地址依赖安排顺序，减少模型已经形成的修订因对象排列先后而无法落库的问题；同批循环引用仍需先创建对象再连接，未保存的草稿会明确保留。

这里的 `belief` 是可改变的定性认识，不是经过校准的概率分布，也没有训练 API 模型的权重。模型仍可能误判反讽、把相关转述当成独立支持，或者在正文中断言自己刚标为暂定的解释。字段和路径只提供修正的条件，不能代替这种能力的实证。目标不是让最终回答处处说“大概”，而是让有把握的共同经历自然进入交流，让猜测保持可更改的身份。

原 [MRAgent](https://arxiv.org/html/2606.06036v1) 的主动记忆重构保留为检索基础；其静态记忆构建不能直接证明这里的长期演化有效。[Generative Agents](https://arxiv.org/html/2304.03442v2) 与 [Reflexion](https://arxiv.org/html/2303.11366v4) 支持把经历与反思送回后续行为这一研究方向，也不能保证本项目中的图或反思质量。明确认可也不是无条件的真值监督：[关于迎合的研究](https://arxiv.org/html/2310.13548v4)说明人类偏好可能奖励好听但错误的回答。需要验证的是后续互动中哪些理解实际改变了、有没有改善参与，而不是记忆条数或模型自述“已经学到”。

本轮真实历史延续观察使用原生 DS 的 22 次 API 调用，包含一次学习和三次 MR 回忆。其中一次回忆完整完成、一次没有交付背景、一次交付了背景但写入失败。模型会根据后来交流更新语境，也仍会把自身复述当成独立支持，或在暂定解释中夹带确信的断言。修复了观察中实际出现的同批前向引用失败，并用原模型输出确认可保存；另有工具参数格式错误和猜测不存在地址的问题，记录保留，没有补造成功结果。历史主回复未由新 MR 产生，不能从这里估算主回答收益。

另一个独立的虚构连续互动诊断使用 11 次原生调用：模型识别了针对固定角色分配的反讽，改写原经历；它将两位参与者实际使用、核验后的方法评价得更有把握，并在后续活动询问中使用该方法，同时保留临时帮忙的适用范围。其输入中的 bot 发言是明示的模拟材料，未运行真实主模型，不是群聊质量验收；背景仍偏长，且没有证明稳定的主动断连或广泛迁移。

目前的判断是：保持不确定性与经验变化贯穿全程值得保留，但可靠的反馈理解、相互依赖的认识如何整体改写，以及取舍需要交付多少信息，仍未解决。下一步优先建立真实主模型参与之后的连续反馈闭环，比较同一基础模型在后续未见交流中的变化；不继续用增加置信度字段或对象数量代替这一目标。开发分支保持实验状态。
